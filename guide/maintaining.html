Hugo / local theme

Edit docs/*.md for explanations. Each document owns its title, group and source links in front matter. New documents appear automatically.

tools.json owns technology descriptions; roadmap.json owns proposals; timeline.json owns history. Configuration previews, application IDs and revisions come directly from repository files. 

cd /saved/nixos-config/guide
./build.sh
xdg-open index.html

Development preview: ./build.sh serve. Each sidebar item has its own HTML page. Open index.html or any section page offline; keep the generated HTML files together. Search, local review checkmarks and copy buttons are optional enhancements. The build checks cross-page links when Node is available.

Before committing

Update the affected guide sources after configuration changes, rebuild the HTML pages, and run node guide/check.mjs guide and git diff --check. The source checks do not replace runtime verification.

GitHub Pages

The repository workflow builds Hugo from source and uploads only generated HTML. Select Settings → Pages → Source → GitHub Actions, then push the reviewed changes or run Publish Shadow handbook. Flat relative links work offline and under a project URL.
